# CargoRoute

Premium multimodal freight & fleet optimization frontend based on the supplied CargoRoute specification.

## Run
```bash
npm install
npm run dev
```

Open the Vite local URL shown in the terminal.

## Included
- React + TypeScript + Vite
- Tailwind CSS + custom CargoRoute design system
- Framer Motion route-optimization sequence
- React Router navigation
- Lucide icons
- Recharts financial charts
- Leaflet/React-Leaflet simulated fleet map
- Interconnected mock vehicles, shipments, capacity and profitability data
- Route optimization workflow
- Intermediate cargo acceptance with capacity checks
- Fleet, tracking, drivers, maintenance, expenses, profitability, investor and reports screens
- Responsive enterprise dashboard
- Demo/simulation labels where data is not real

All logistics, financial and tracking information is mock frontend data.
